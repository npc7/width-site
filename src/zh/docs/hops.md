## 跳数是什么

**一跳**就是一次转账。你筛查的地址直接和谁有过转账，那个对手方就在第 1 跳；对手方再往外一层，是第 2 跳，以此类推。

- **流入跳数**（`inflow_hops`）：往上游追，回答「这个地址的钱是从哪来的」。
- **流出跳数**（`outflow_hops`）：往下游追，回答「这个地址的钱去了哪里」。

## 默认值和推荐值

| | 流入 | 流出 | 说明 |
|---|---|---|---|
| 控制台默认 | 3 | 1 | 适合绝大多数日常筛查 |
| API 不传时 | 3 | 3 | 建议显式传入你需要的值 |
| 充值筛查（看来源） | 3 | 0 或 1 | 只关心钱从哪来 |
| 提现 / 转账前（看去向） | 0 或 1 | 1 | 只关心对方是谁、钱打给谁 |
| 只查标签（制裁名单类） | 0 | 0 | 不追资金，只看地址自己有没有标签，最快 |
| 案件调查 | 按需加深 | 按需加深 | 越深越慢，建议用资金追踪功能 |

<div class="callout tip"><b class="t">建议总是显式传跳数</b>不传时按默认值处理。把你选定的跳数写进请求，也写进你的内部规则说明，监管问起来有据可查。每次筛查用了多少跳，都会记在快照里。</div>

## 为什么流入和流出不一样

**钱流进来**：两三跳之外的制裁资金、黑客资金流进你的地址，是实打实的「污染」。如果你收了这笔钱，冻结可能落到你和你的用户头上。所以流入值得多追几跳。

**钱流出去**：钱离开之后又转了两三跳去了哪里，你几乎无法控制，追责的意义有限。唯一的例外是**直接流出**：直接把钱打给制裁实体，是和直接收钱一样严重的信号。

这也反映在默认评分矩阵里：流入的直接、2 跳、3 跳以上基础分是 80 / 50 / 40；流出的直接是 80，但 2 跳只有 10、3 跳以上只有 5。见 [评分矩阵与四档处置](/zh/docs/scoring/)。

## 跳得越远，门槛越高

远距离的关联很容易是巧合。DART 的内置规则对第 2 到第 5 跳的「分层暴露」规则设了递增的风险资金占比门槛：

| 跳数 | 默认门槛（风险资金占比） |
|---|---|
| 1 跳（直接） | 金额超过 10 即命中 |
| 2 跳 | ≥ 5% |
| 3 跳 | ≥ 10% |
| 4 跳 | ≥ 15% |
| 5 跳 | ≥ 20% |

所以加深跳数不会让结果「越查越脏」：远处的弱关联达不到门槛，不会命中。门槛的含义见 [资金占比与门槛](/zh/docs/fund-share/)。

## 0 跳是什么意思

- **一边是 0**：这个方向不追。例如流入 1、流出 0，只看谁直接给这个地址打过钱。
- **两边都是 0**：不追任何资金，只把地址**自己的标签**拿去和规则集里的「自身命中」规则比对。适合制裁名单、黑名单这类「只问这个地址本身是谁」的场景，速度最快。结果里 `dataStatus.paths` 会显示 `labels_only`。

<div class="callout warn"><b class="t">传 0 和不传是两回事</b>传 0 表示这个方向不查；不传表示按默认值（3 跳）查。如果你只想查一个方向，请明确把另一个方向传成 0。</div>

## 跳数和速度

每多一跳，资金图的规模大约成倍增长，耗时也随之增加。经验上：

- 两边都是 0：通常在 1 秒内返回。
- 流入 1 到 3 跳：大多数地址几百毫秒到几秒。
- 交易非常活跃的地址、深跳数：可能需要更久，建议用异步模式（`mode: async`），见 [同步还是异步](/zh/docs/api-async/)。

另外，「每跳最大节点数」（默认 200）限制每一跳最多展开多少个对手方，用来控制图的规模；「最小金额」（默认 10）过滤掉粉尘转账。

## 怎么选：一个简单的判断

1. 你关心的是**钱从哪来**（收款、充值、入金）→ 流入为主，3 跳起步。
2. 你关心的是**钱给了谁**（提现、付款、转账前）→ 流出为主，1 跳。
3. 你只想知道**这个地址本身是谁**（制裁、黑名单）→ 0 / 0。
4. 你在**调查一个案子** → 用资金追踪，按需加深，配合人工判断。

## 常见问题

<details><summary>我传了流入 1、流出 0，为什么结果里还有流出方向的命中？</summary>

传 0 就是不查这个方向。请检查请求里是否真的传了 <code>outflow_hops: 0</code>（不传会按默认 3 跳），以及用的是不是 v3 接口。快照里记录了这次筛查实际使用的跳数，可以对照查看。

</details>

<details><summary>跳数越多是不是越安全？</summary>

不一定。跳数越多，耗时越长；因为有递增门槛，远处的弱关联本来也不会命中。日常筛查流入 3 跳已经能覆盖绝大多数真实风险。需要更深的分析时，用资金追踪逐跳看。

</details>
