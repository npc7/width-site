## 一句话

**DART 回答一个问题：这个地址（或这笔交易）的钱，和哪些风险对象有关、关系有多近、占多大比例，以及你该怎么处置。**

它覆盖稳定币 USDT 和 USDC，支持地址筛查（KYA）、交易筛查（KYT）、只看标签的制裁筛查、EVM 地址的全链筛查、持续监控和资金追踪。所有结论都附带路径证据，能解释，也能复核。

## 一次筛查的五步

```text
输入            路径调查              路径匹配规则集      评分规则集          输出
地址 / 交易  →  按时间顺序追资金   →  逐条路径比对规则  →  折算成 0–100 分  →  分数 + 处置
                得到带标签的资金图    产出命中列表        按档位给出处置      + 重点关注 + 快照
```

1. **输入**：一个地址（KYA）或一笔交易哈希（KYT），选链和币种。控制台会自动识别链和类型。
2. **路径调查**：从这个地址出发，往上游追「钱从哪来」，往下游追「钱去了哪」，跳数可以配置。默认只保留**时间上成立**的路径：每一跳都先到账、后转出。图上每个对手方都带标签，例如交易所、制裁、黑客、混币器。见 [为什么按时间顺序追资金](/zh/docs/time-order/)、[跳数怎么设计](/zh/docs/hops/)。
3. **路径匹配规则集**：把每条路径拿去和规则比对，例如「2 跳之内碰到制裁地址，且风险资金占比 ≥ 5%」。这一步只回答「违规吗、违反哪条」，不打分。
4. **评分规则集**：把命中折算成 0–100 分。按「方向 × 跳数 × 严重度」查基础分，再乘以风险资金占地址链上总流量的比例。地址自己带严重标签时，直接按自身命中计分。见 [评分矩阵与四档处置](/zh/docs/scoring/)。
5. **输出**：
   - **分数和处置**：通过、复核、加强尽调、拦截四档；
   - **重点关注（★）**：你点名要盯的规则一旦命中，单独列出，不管分数多少；
   - **命中明细**：每条命中的对手方、跳数、金额、占比、时间；
   - **数据完整性**：这次结果背后的数据是否读全（`dataStatus`）；
   - **快照**：请求参数和完整结果自动存档，不可篡改。

<div class="callout tip"><b class="t">两套规则集，各管一件事</b>路径匹配规则集决定「什么算违规」，评分规则集决定「有多严重、怎么处置」。同一批命中，换一套评分规则集，分数和处置会变，命中列表不变。详见 <a href="/zh/docs/rulesets/">两套规则集，三种规则形态</a>。</div>

## 它能回答哪些问题

| 你的问题 | 用什么 |
|---|---|
| 这个地址能不能打交道？ | [地址筛查 KYA](/zh/docs/kya/) |
| 这笔充值的钱从哪来？这笔提现打给了谁？ | [交易筛查 KYT](/zh/docs/kyt/) |
| 这个地址本身在不在制裁名单上？ | [制裁筛查与只看标签](/zh/docs/sanctions/) |
| 同一个 0x 地址在别的链上干不干净？ | [EVM 多链与跨链](/zh/docs/cross-chain/) |
| 我的银行点名的对象，有没有沾边？ | [自定义规则集与重点关注](/zh/docs/custom-rulesets/) |
| 今天通过的地址，以后变脏了怎么办？ | [持续监控](/zh/docs/monitoring/) |
| 一笔被盗资金最后去了哪里？ | [资金追踪与调查](/zh/docs/tracing/) |

## 给谁用

- **交易所**：充值看来源、提现看去向，充提分开设规则集。
- **钱包**：转账前提醒、收款后提醒。
- **支付与 U 卡**：资金进入法币通道前筛来源。
- **托管与 MPC 归集**：先筛再归集。
- **合规调查员和执法机构**：从一条线索出发追资金，留存证据。

## 三种用法，一个账号

| 方式 | 适合谁 | 入口 |
|---|---|---|
| 控制台 | 合规人员：手动筛查、复核、查快照、调规则 | width.info |
| API | 工程团队：把筛查嵌进充提和开户流程 | `https://api.width.live` |
| MCP | AI 助手：用自然语言筛查、解释结果、改规则 | `https://api.width.live/mcp` |

控制台、API 和 MCP 用同一个账号、同一份额度和同一批快照。你复制、修改过的规则集属于这个账号，三种方式都可以按 id 引用。

接入 DART，免费用到 2028 年 12 月 31 日。
