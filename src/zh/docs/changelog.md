按上线日期倒序。新的平台规则集、接口参数、控制台功能都会记在这里。

## 2026-11-20

- **EVM 地址的标签可以跨链合并（`all_chain_labels`）**：同一个 0x 地址在其他 EVM 链上的标签，也当作它自己的标签参与判定。KYA、KYT、全链 KYA 和 MCP 都可以用，默认关闭，关闭时结果不变。从其他链带来的标签列在 `otherChainTags` 里，并标明来源链。合约类标签不跨链。见 [EVM 多链与跨链](/zh/docs/cross-chain/)。
- **持续监控也能带上 `all_chain_labels`**；监控页现在可以修改所有参数，包括评分规则集、场景、到期时间和单边 0 跳。

## 2026-11-19

- **全链标签查询**：标签库支持一次查出一个地址在所有链上的标签，为 `all_chain_labels` 提供数据。

## 2026-11-17

- **同步筛查更快**：需要实际调查的同步请求，中位耗时由约 2.2 秒缩短到约 0.6 秒。
- **结果标明数据是否完整（`dataStatus`）**：区分「数据完整、没发现问题」和「部分数据没读到」。没有流水的地址也返回全 0 的地址总览。上游调查失败的任务返回 `FAILED`，不计费。见 [数据完整性与快照](/zh/docs/data-status/)。
- **交易追踪：跨链和分摊**：跨链去向支持 USDC CCTP，同一个 0x 地址在两条链上分开显示；资金分摊在按比例之外，新增 FIFO（先进先出）和 LIFO（后进先出）。
- **跨链卡片**：KYA、KYT 结果下方显示这个地址或交易的跨链记录、对侧标签，以及同一私钥在其他链上的地址。只展示，不计分。
- **筛查页三层解释**：结果顶部按「参数 → 规则 → 评分」列出这次用了什么；分数改成「流入 / 流出 × 直接 / 2 跳 / 3 跳以上」的矩阵，每格标出上限。
- **重新判定与对比**：只改规则、评分或豁免时，可以用原任务重新判定，不算一次新的筛查；前后两次结果并排对比。也可以直接改评分参数试算。
- **交易所出入金页面公开**：不用登录就能查看各交易所的出入金情况，明细导出仍需登录。

## 2026-11-16

- **可以只查一个方向**：KYA、KYT 的跳数传 0，表示这个方向不追；两边都传 0，只看地址自己的标签；不传仍按默认 3 跳。KYT 按 `screen_direction` 决定调查付款方还是收款方。见 [跳数怎么设计](/zh/docs/hops/)。

## 2026-11-12

- **快照列表显示命中规则**：控制台「合规 › 快照」列表里直接显示每次筛查命中了哪些规则，不用逐条点开。

## 2026-11-11

- **USDC 跨链与新链**：接入 Circle 的 USDC 跨链协议 CCTP，按 Circle 官方编号配对跨链转账；新增 Arbitrum、Base、Polygon、Arc 四条链的 USDC 追踪。

## 2026-11-09

- **谷歌账号登录**：可以用谷歌账号注册和登录控制台。

## 2026-11-08

- **USDT 和 USDC 一次筛**：全链 KYA 支持 `tokens` 参数，例如 `{"chains":["Ethereum"],"tokens":["usdt","usdc"]}`，一次筛一条链上的两个币种，每个币种一份结果，较差的排在前面。

## 2026-11-07

- **全链 KYA**：`POST /api/v3/screen/kya/multi`。一个地址自动探测各条链、各个币种的通道，有流水或标签的通道逐个筛查，最差的排在最前；每个通道单独存快照、单独计费，空通道不收费。控制台新增「全部链（自动识别）」，MCP 新增对应工具 `screen_address_all_chains`。

## 2026-11-06

- **FinCEN 9714 平台规则集**：FinCEN 依据 9714 条款对某交易所发布命令（这是命令，不是 OFAC 制裁）。命令发布当天，DART 上线对应的平台规则集，控制台和 API 里直接选用。相关地址在默认设置下不会被交易所豁免放过，多跳关联也能看到。见 [新的制裁或点名命令出来了怎么办](/zh/docs/playbook-new-actions/)。
