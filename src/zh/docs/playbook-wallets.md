## 一句话

**转账前问「对方是谁」，收款后问「这笔钱从哪来」。** 钱包要的是一句准确的提示：快到不卡转账，准到用户愿意相信。

## 转账前：查收款地址

用户输入收款地址后、确认页之前，调用地址筛查。

### 两种做法

| 做法 | 参数 | 速度 | 能看到什么 |
|---|---|---|---|
| 只查标签 | `inflow_hops: 0`，`outflow_hops: 0` | 最快，通常 1 秒内 | 收款地址自己有没有制裁、恐怖融资、执法冻结等标签 |
| 加看一跳 | `inflow_hops: 0` 或 `1`，`outflow_hops: 1` | 稍慢 | 另外看到收款方直接和哪些风险地址有往来 |

```json
POST https://api.width.live/api/v3/screen/kya
X-Api-Key: YOUR_KEY

{
  "chain_name": "Ethereum",
  "address": "0x…",
  "inflow_hops": 0,
  "outflow_hops": 0,
  "all_chain_labels": true
}
```

只查标签时，结果里 `dataStatus.paths` 是 `labels_only`。EVM 地址建议打开 `all_chain_labels`：收款地址在别的链上被标了制裁，这条链上也能查到。

### 别让用户等

- 用户一输入完整地址就发请求，不要等到点「确认」。
- 给请求设一个超时。超时后可以先放行确认页，结果回来再补提示；不要因为风控接口慢就卡死转账。
- 追得深的筛查用异步（`mode: async`），见 [同步还是异步](/zh/docs/api-async/)。
- 同一个地址短时间内反复转账，可以在你这边缓存结果一段时间。

## 收款后：查资金来源

新资金到账后，对这笔交易做流入方向的 KYT：

| 参数 | 推荐值 |
|---|---|
| 接口 | `POST /api/v3/screen/kyt` |
| `screen_direction` | `in`（筛付款方） |
| `inflow_hops` / `outflow_hops` | 3 / 0 |
| `cex_immune` | `true`：从交易所提币过来的钱不误报 |
| `mode` | `async`，收款提醒不需要实时 |

来自发行方冻结、黑客、诈骗资金时，推送提醒，让用户及早知道，减少之后被连带冻结的风险。

## 提示怎么写：三档

不要每笔都弹警告。用户看多了会忽略，误报多了会流失。建议按处置档位分三档：

| 档位 | 对应结果 | 怎么提示 | 示例文案 |
|---|---|---|---|
| 不打扰 | 通过（`accept`） | 不提示 | — |
| 轻提示 | 复核（`review`），或有 ★ 命中 | 确认页上一行小字，不拦 | 「该地址与公开风险来源存在间接关联，请确认收款方身份。」 |
| 强提醒 | 加强尽调、拦截（`edd` / `block`），或自身命中 | 弹窗，需用户再次确认 | 「该地址出现在官方制裁名单中。向其转账可能导致你的资产被冻结。是否继续？」 |

写文案的三条原则：

1. **只说命中了哪类公开来源**：官方制裁名单、发行方冻结、公开报道的安全事件。
2. **不给个人地址下定性**：不写「这是诈骗地址」「对方在洗钱」。
3. **决定权留给用户**：说明风险，由用户决定是否继续。拦截与否是钱包自己的政策。

做决策请用 `score.verdict` 和 `highlightedHits`，不要用 `riskScore`。见 [怎么读结果](/zh/docs/reading-results/)。

## 隐私

- **只传链上信息**：筛查只需要地址或交易哈希。不要在请求里带用户 ID、手机号、邮箱等身份信息。
- **在隐私政策里说明**：告诉用户你会把收款地址、到账交易提交给风控服务做检查。
- **快照在你的账号下**：每次筛查都会存成快照。如果你要把结果和用户关联，在你自己的系统里保存快照编号，不需要把用户信息交给 DART。

## 案例：某头部自托管钱包

一家头部自托管钱包接入 DART 后，一周内从开始调用到单日 7 万次以上。跳数等参数按他们自己的风控要求单独配置。FinCEN 9714 命令发布当天，他们直接选用平台规则集，就能在充提中识别相关资金。

## 常见问题

<details><summary>用户粘贴的 EVM 地址在好几条链上都有余额，查哪条？</summary>

用全链 KYA（<code>POST /api/v3/screen/kya/multi</code>），自动识别这个地址在哪些链、哪些币种上有流水，一次筛完，最差的一条排在最前。只对有内容的通道计费。见 [EVM 多链与跨链](/zh/docs/cross-chain/)。

</details>

<details><summary>收款地址是交易所充值地址，会提示吗？</summary>

默认不会。普通交易所地址按豁免直接返回 0 分。被制裁或带其他高风险标签的交易所不豁免，照常提示。

</details>
