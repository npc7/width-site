## 一句话

**我们负责把新动作做进标签和规则集，你负责选用、回看和留档。** 监管检查时常被问到的一个问题是：「新名单出来后，你多快开始筛？有没有回头查过存量客户？」这一页就是答这个问题的流程。

## DART 会做什么

- **收录标签**：把官方动作涉及的实体和地址收录进标签库。
- **发布平台规则集**：针对某一类动作，发布一套现成的规则集，控制台和 API 里直接选用。
- **当天上线**：例如 FinCEN 依据 9714 条款对某交易所发布的命令，11 月 6 日发布，DART 当天上线了对应的平台规则集。相关地址在默认设置下不会被交易所豁免放过，多跳关联也能看到。

规则集是数据，不是写死的代码。所以新动作出来，你这边不需要改一行代码，只需要换一个规则集 id，或者在自己的规则集里加一条规则。

## 你要做的四件事

### 1. 分清动作的性质

不同的动作，处置口径不同：

| 动作类型 | 例子 | 常见处置 |
|---|---|---|
| 制裁名单 | OFAC SDN 新增地址 | 命中即拦截、冻结，按要求上报 |
| 点名命令 | FinCEN 依 9714 条款发布的命令 | 受约束的机构不得与被点名方往来资金。这是**命令，不是制裁**，被点名方没有被列入 SDN 名单。直接拦截、人工复核还是只做标记，要结合你和美国金融体系的往来来定 |
| 执法冻结 | 发行方冻结、执法扣押 | 命中即复核或拦截 |

具体口径建议和你的法律顾问确认。见 [各地监管要求对照](/zh/docs/regulatory-map/)。

### 2. 选用平台规则集，或加重点关注

**做法一：直接选用平台规则集。** 筛查时把 `ruleset_id`（KYT 用 `in_ruleset_id` / `out_ruleset_id`）换成平台规则集的 id，控制台里在规则集下拉框里选。平台规则集只读；要改分值和处置，复制一份再改。

<div class="callout warn"><b class="t">每次筛查只用一套路径匹配规则集</b>如果你平时用的是自己复制改过的规则集，换成平台规则集后，这次筛查就只跑平台规则集里的规则。先在规则集页面看清它包含哪些规则，再决定是直接换用，还是把它的规则加进你自己的规则集。</div>

**做法二：在自己的规则集里加一条 ★ 规则。** 适合「沾到就要知道」但不一定要拦的情况：

```json
POST https://api.width.live/api/v3/rulesets/rule/create
X-Api-Key: YOUR_KEY

{
  "ruleset_id": 1234,
  "rule_code": "MY_NAMED_ENTITY_ANY_HOP",
  "name": "与被点名实体有资金往来",
  "risk_level": "high",
  "action": "review",
  "direction": "both",
  "min_hops": 1,
  "max_hops": 3,
  "conditions": [
    { "parameter": "tertiary_category", "operator": "IN", "value": ["<实体名>"] }
  ],
  "is_highlighted": true
}
```

`ruleset_id` 填你自己的规则集（1234 只是占位）。实体名按标签里的写法填，不区分大小写。★ 只影响展示，不改分数；要让它影响处置，设好 `risk_level` 和 `action`。见 [自定义规则集与重点关注](/zh/docs/custom-rulesets/)。

### 3. 回看存量客户地址

新动作只影响之后的筛查是不够的。你的存量客户里，可能已经有人和被点名方有过往来。OFAC 对虚拟货币行业的合规指引也要求持续筛查，并按风险回溯重筛。

| 方式 | 适合 |
|---|---|
| CSV 批量导入，一次性重新筛查 | 存量地址多，一次回看 |
| API 逐个重新筛查（建议异步） | 已有自动化流程 |
| 持续监控 | 回看之后，长期盯住高风险客户地址 |

回看时：

- 用新的规则集重新筛，保留每个地址的快照编号；
- 想确保读到最新的链上数据，加 `force_run: true`（按一次完整调查的开销计）；
- 先从风险高、金额大、和被点名方所在市场有业务往来的客户开始。

### 4. 记下你的响应

监管问起时，你要能拿出一条时间线：

```text
官方动作：[名称、编号、发布日期]
性质判断：[制裁 / 命令 / 冻结]，依据：[法律意见或内部政策]
规则生效：[日期]，规则集：[名称和 id]，变更内容：[新增或修改了哪些规则]
存量回看：[范围、地址数、开始和完成日期]
回看结果：[命中数量、处置情况、快照编号清单]
复核人：              日期：
```

快照会记下每次筛查用的规则集和结果，可以作为这条时间线的证据。见 [怎么向监管解释你的规则](/zh/docs/explain-to-regulator/)。

## 怎么第一时间知道

- 看 [更新日志](/zh/docs/changelog/)，新的平台规则集会写在这里；
- 看 DART 博客，新的平台规则集上线时会发公告；
- 你关注的某个动作还没看到对应的规则集，[联系我们](/zh/contact/)。
