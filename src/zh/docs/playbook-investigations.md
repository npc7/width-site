## 筛查和追踪不是一回事

| | 筛查（KYA / KYT） | 资金追踪 |
|---|---|---|
| 问的问题 | 这个地址能不能收、能不能放行 | 这笔钱从哪来、最后去了哪 |
| 输出 | 分数、处置档位、命中规则 | 一张逐跳展开的资金图 |
| 参数取向 | 稳定、可复现，日常默认值 | 按案件需要放宽、加深 |
| 谁来用 | 系统自动跑 | 调查员人工研判 |

筛查结果进了复核或加强尽调队列，或者你接到一起被盗、诈骗案件，就该打开资金追踪。

## 调查流程

### 1. 定起点

被盗地址、可疑充值、举报地址、涉案交易哈希都可以作为起点。系统自动识别链和币种。先对起点做一次筛查，看它自己有什么标签、直接对手方是谁。

### 2. 逐跳展开

- **往上游**：钱从哪来。适合复核可疑充值。
- **往下游**：钱去了哪。适合追被盗资金、找冻结点。
- **按需加深跳数**：日常筛查流入 3 跳、流出 1 跳就够；调查时可以追得更深。跳数越深，图越大、越慢。
- **控制展开范围**：用「最小金额」过滤粉尘，用「每跳最大节点数」先看主干。

图上每个节点都带标签和风险级别。路径追到交易所等已知实体会停下，便于你确认「钱到了哪家交易所」。DEX 兑换只认同一笔交易里的兑换结果；借贷、收益协议、跨链桥这类公共资金池不往里穿透，因为池子里是别人的钱。

### 3. 选资金分摊方式

一个地址收了好几笔钱、又转出好几笔，被追的那笔钱「算」到哪笔转出上？有三种算法可选：

| 算法 | 做法 | 适合 |
|---|---|---|
| 按比例 | 按金额比例分摊到每笔转出 | 默认，适合快速看全貌 |
| FIFO（先进先出） | 先到的钱先转出 | 资金按时间顺序周转的地址 |
| LIFO（后进先出） | 后到的钱先转出 | 收到后很快转走的中转地址 |

FIFO / LIFO 需要逐个读取地址的转账账本。账本读不全的地址会退回按比例分摊，并在图上标出来。案件报告里请写明用的是哪种算法。

### 4. 跨链续追

USDC 通过 Circle 官方的 CCTP 跨链时，DART 按 Circle 的官方编号配对，在目标链上接着追。目前覆盖以太坊、Arbitrum、Base、Polygon、Arc 等链的 USDC。同一个 `0x…` 地址在两条链上会画成两个节点，便于区分。筛查结果旁的跨链卡片也会列出这个地址的跨链记录和对侧标签。见 [EVM 多链与跨链](/zh/docs/cross-chain/)。

### 5. 时间顺序：只在调查时放宽

DART 默认要求资金先到账、后转出（强制时序）。日常筛查请一直开着。

调查时可以关掉，看所有**可能**的关联，再由人工判断。但要记住：

- 关闭时序得到的路径里，有一部分在时间上不可能发生；
- 这些路径适合当线索，**不适合**直接作为拦截用户或认定资金来源的依据；
- 写进报告的结论，建议用开启时序的结果，或逐笔核对时间。

见 [为什么按时间顺序追资金](/zh/docs/time-order/)。

## 证据：用快照固定

每次查询都存成不可篡改的快照，记录当时的参数（起点、跳数、时序、最小金额、规则集）和完整结果。

- 在报告里引用快照编号，审阅的人可以按编号调出原始结果核对；
- 链上数据和标签会更新，**重新查询的结果可能不同**，所以证据以快照为准；
- 路径里每一跳都有地址、金额和时间，都是可以在区块浏览器上独立核对的链上事实。

<div class="callout tip"><b class="t">报告里写清楚口径</b>起点、方向、跳数、是否强制时序、资金分摊算法、最小金额、查询时间、快照编号。别人按同样的口径能复现你的结论。</div>

## 怎么申请支持

| 你是 | 怎么做 |
|---|---|
| 合规团队，在复核一笔可疑交易 | 资金追踪需要单独开通，[联系我们](/zh/contact/) |
| 执法机构、有调查职能的政府部门 | 用机构邮箱提交申请，附公函或证件，[执法合作申请](/zh/contact/?type=lea)。核实后开通调查员账号，每次查询留痕 |
| 重点案件，需要报告或冻结协助 | 可申请分析师出追踪报告；对接稳定币发行方、交易所冻结时，我们提供证据包。冻结由发行方或交易所决定，我们不承诺冻结结果 |

所有数据请求都经法务审核。执法合作的详细说明见 [执法机构合作](/zh/partners/lea/)。

## 常见问题

<details><summary>为什么我在别的工具里看到的路径，这里没有？</summary>

最常见的原因是那条路径在时间上不成立，被时序排除了。也可能是跳数、最小金额或交易所豁免不同。把两边的设置对齐再比。

</details>

<details><summary>能把追踪结果导出吗？</summary>

可以导出追踪报告。起点的筛查结果也可以按快照编号通过 API 读回（<code>GET /api/v3/snapshots/{snapshotId}</code>）。

</details>
