## 开始之前

- 一个 DART 账号。还没有的话，[联系我们](/zh/contact/)开通。接入 DART，免费用到 2028 年 12 月 31 日。
- 一个你想查的地址或交易哈希。第一次可以用你自己平台的一个充值地址试试。

登录 width.info 后，顶部横条会显示剩余额度和有效期。每次筛查消耗一次额度。

## 第一步：发起筛查

进入 **「合规 › 筛查」**，在输入框里粘贴地址或交易哈希。

系统会**自动识别链和筛查类型**，例如「Ethereum · KYA」或「Tron · KYT」。识别结果会显示在输入框旁边，运行按钮的括号里也会写明类型。EVM 地址还可以选择全部链，一次筛查这个地址有流水的所有链，见 [EVM 多链与跨链](/zh/docs/cross-chain/)。

输入框下面有**两个规则集下拉框**：

| 下拉框 | 决定什么 | 默认 |
|---|---|---|
| 路径匹配规则集 | 什么算违规：哪些路径、哪些对手方会命中 | 内置默认规则集（标 ★ 的那个） |
| 评分规则集 | 有多严重：命中怎么折算成分数和处置 | 内置资金占比评分 |

第一次用，两个都保持默认就好。如果你的团队已经复制过自己的规则集，或者要用平台针对某个官方动作发布的规则集，在这里选。

## 第二步：看一眼高级选项

点开「高级选项」，可以看到这些设置。第一次建议全部保持默认：

| 选项 | 默认 | 说明 |
|---|---|---|
| 时间窗口 | ALL | 只分析某段时间内的转账。缩小窗口会明显变慢、路径更少，没有明确需要就保持 ALL |
| 币种 | USDT | 也支持 USDC |
| 流入 / 流出跳数 | 3 / 1 | 往上游、下游各追几跳。0 表示这个方向不追。跳数越多越慢 |
| 最小金额 | 10 | 低于这个金额的转账不纳入分析，过滤粉尘 |
| 每跳最大节点数 | 200 | 每一跳最多展开多少个对手方，控制图的规模 |
| 强制时序 | 开 | 每一跳的时间不早于上一跳，资金只能沿时间正向流动 |
| 免疫交易所地址 | 开 | 普通交易所地址直接返回 0 分；带制裁等高风险标签的交易所照常筛查 |

各选项背后的道理见 [跳数怎么设计](/zh/docs/hops/)、[为什么按时间顺序追资金](/zh/docs/time-order/)、[交易所豁免](/zh/docs/exchange-exemption/)。

点击运行。大多数地址几秒内出结果，交易非常活跃的地址会久一些。

## 第三步：读结果摘要

结果页顶部有三个页签：**摘要 / 图谱 / 历史**。先看摘要：

- **分数和处置**：0–100 分，以及通过、复核、加强尽调、拦截中的一档。由评分规则集算出。
- **自身命中标记**：地址自己就带严重标签（例如它本身是制裁地址）时会标出来，分数直接拉满。
- **地址自身的标签**：这个地址是谁，例如交易所、支付机构，或者没有标签。
- **命中路径数和去重后的风险边数**：有多少条路径命中了规则。
- **地址总览**：总流入、总流出、余额、活跃区间，以及直接入金、间接入金、流出各自的风险资金占比。

结果顶部还会按 **「参数 → 规则 → 评分」** 三层列出这次用了什么设置、哪些规则命中、分数怎么来。分数以「流入 / 流出 × 直接 / 2 跳 / 3 跳以上」的矩阵展示，每一格标出上限。

**图谱**页把资金流画出来，每个节点带标签；**历史**页是这个地址过往的筛查记录。

## 第四步：核对分数从哪来

摘要下方有两块：

- **分数计算依据**：这次用的计算口径（累加，还是自身命中），以及每一格的推导，例如「风险流入 ÷ 总流入 × 基础分 = 得分」，对应矩阵里的哪一格。
- **触发规则**：命中了哪些规则，每条的严重度、建议动作和命中路径条数。展开可以看每条路径：对手方是谁、第几跳、多少钱、什么时间。★ 规则的命中排在最前面。

如果你想试试换个规则集或评分规则集会怎样：只改规则、评分或交易所豁免时，可以用原来的调查**重新判定**，不算一次新的筛查，前后两次结果会并排对比。也可以直接改评分参数试算。

<div class="callout warn"><b class="t">0 分但显示「复核」？</b>通常是评分规则集的档位设成了从 0 开始就是复核。默认档位里 0–19 是通过。见 <a href="/zh/docs/scoring/">评分矩阵与四档处置</a>。</div>

## 第五步：找到这次的快照

每次筛查都会自动生成一份**快照**，记录当时的请求参数和完整结果，不可篡改。进入 **「合规 › 快照」** 就能找到。复核、审计、监管检查时，按快照调出当时的证据，不需要重新筛查。
